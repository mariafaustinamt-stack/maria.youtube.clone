# YouTube Clone

##  Project Description

A frontend clone of YouTube created using HTML and CSS. This project recreates the visual appearance and layout of YouTube's homepage, including its navigation bar, sidebar, search section, and video feed.

## Features

- YouTube-inspired homepage design.
- Navigation sidebar with Home, Explore, Subscriptions, Originals, YouTube Music, and Library.
- Search bar interface.
- Video thumbnail grid layout.
- Video titles, channel names, and view details.
- Clean and organized user interface.


## What I Learned

- Structuring web pages using HTML.
- Styling web elements using CSS.
- Creating layouts using CSS Grid and Flexbox.
- Working with images and positioning elements.
- Understanding how to recreate real-world website interfaces.
- Improving frontend design and layout skills.
